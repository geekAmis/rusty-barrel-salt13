# БРЕНД-КИТ · «РЖАВАЯ БОЧКА»

## Логотип

- Основной: две строки, «РЖАВАЯ» / «БОЧКА», антиква с ржавыми подтёками.
- Минимальный размер: 96 px по ширине.
- Охранное поле: 0.25 высоты логотипа.
- Нельзя: растягивать, менять цвет, добавлять тени, ставить на светлый фон без плашки.

## Шрифты

- Заголовки: антиква с высоким контрастом (в игре — системная serif).
- Интерфейс: моноширинный, разрядка 0.18em.
- Документы: моноширинный, выключка влево, без переносов.

## Иконка

- `android/app/src/main/res/mipmap-*/ic_launcher.png` — основная.
- `ic_launcher_round.png` — круглая.
- Сюжет: ржавая бочка №9, бирка, капля рассола.
- Фон: почти чёрный, без градиентов.

## Голос

- Первое лицо, протокольный тон, короткие фразы.
- Не шутить в ужасе. Юмор — только канцелярский, чёрный.
- Слово «смена» — с заглавной только в ритуальном контексте.
