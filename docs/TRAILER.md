# ТРЕЙЛЕР v2.1.1 · 52 СЕКУНДЫ

Реальный геймплей, записанный покадрово через CDP, а не слайд-шоу из скриншотов.
Формат: 1280×720, 30 fps. Звук: низкий индустриальный гул (сгенерирован, без музыки из игры).

Готовые файлы:

- `docs/rusty-barrel-trailer.webm` — VP9 + Opus, ~2.8 МБ;
- `docs/rusty-barrel-trailer.mp4` — H.264 + AAC, ~3.6 МБ, для плееров без VP9.

## Как пересобрать

```powershell
cd D:\megaGame
Start-Process node -ArgumentList "tools/serve.mjs","8123" -WindowStyle Hidden
node tools/capture-trailer.mjs   # ~85 с, пишет tools/trailer-frames/*.jpg + meta.json
node tools/build-trailer.mjs     # собирает WebM и MP4, вжигает субтитры
```

`capture-trailer.mjs` проходит 10 сцен: меню, геймплей, инвентарь, торговля, диалог, катсцена, замок, босс, карта, концовка. Движение, стрельба и клики выполняются в самой игре, поэтому в кадр попадают HUD, тултипы, тосты и анимации.

`build-trailer.mjs` берёт из `meta.json` реальные таймстемпы кадров, режет загрузочные паузы, собирает concat-лист, генерирует ASS-субтитры и кодирует VP9/Opus + H.264/AAC.

## Старое

`docs/trailer.html` и `tools/render-trailer.mjs` — прошлый вариант со скриншотами и рекламными титрами. Оставлены как архив, в сборке не участвуют.
