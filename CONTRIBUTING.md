# Как помочь проекту

Спасибо, что зашёл. Это одностраничная мобильная игра на vanilla JS и Canvas 2D — без сборщика, без фреймворков и без магии.

## Локальный запуск

```bash
node tools/serve.mjs 8123
```

Открой `http://127.0.0.1:8123` в ландшафтном режиме 640×360.

## Перед PR

```bash
node --check game/js/*.js
node tools/test-story.mjs
node tools/test-platform.mjs 200
node tools/e2e.mjs   # нужен запущенный сервер на 8123
```

## Правила

- Не ломай один стик: <50% — прицел, >50% — движение.
- Уровни должны оставаться проходимыми. После генерации проверяй BFS-достижимость.
- Монстры — твёрдые тела, без наложения друг на друга и на игрока.
- Новые предметы добавляй в `game/js/items.js`, иконку — через `iconFile`/`iconSvg`.
- Новые терминалы и письма — в `game/js/terminals.js`.
- Не коммить `res/`, `build/`, APK/AAB, keystore и записи трейлера.
- Для UI-правок приложи скриншот до/после.

## Стиль

- Русский интерфейс, короткие фразы, канцелярский ужас.
- Никаких «магических» кнопок: действие — контекстная плашка.
- Пасхалки приветствуются, если они не ломают баланс.
